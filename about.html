About the project

A production-style academic web application demonstrating an end-to-end NLP classification pipeline.

How it works

Submitted text is cleaned with reusable NLTK preprocessing, transformed into TF-IDF features, and classified by a saved Logistic Regression model. The API records the model output and confidence for the authenticated user.

Important limitation

The model learns patterns from its training dataset. It does not independently verify sources or establish objective truth. Dataset bias, topic shift, satire, missing context and adversarial writing can cause errors. Important claims should be checked against reliable sources.
